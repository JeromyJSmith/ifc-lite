## 3. The dominant defect class

**A check that passes without asserting anything.** Roughly ten instances were
found on 2026-08-01/02 and six more in the closing session. Every one was green
before it was attacked, and **not one was found by reading the code**:

- a verifier that read its trust root out of the bundle it was verifying
- a cap implemented as `statSync().size`, inapplicable to a FIFO (512 MiB
  streamed against a 1 MiB cap)
- a cross-check that computed both deviations, printed them, and discarded them
- a histogram that could never report a swept solid; a flag that could never be
  false
- **B5.5's own exam**, invariant under the rigid Z-shift that was the defect
- a brute-force probe reporting `oracleIdentifiedTrueKey` that no caller read,
  so a drifted stream-key format would have published the machine's
  string-comparison speed as the cost of defeating a salt
- a truth map and a leaderboard row that could name **different universes**
  without complaint

The antidote that works: **assert WHY a check fails, not that it did.** A
reason-assertion is what caught the shared-temp-dir race, where a catch-only
assertion reported `PASS` in 2 of 3 runs.

Second-order lesson, learned the hard way in the salt module: **six silent
drops, two of them introduced by the fix for the previous one.** A fix that
lands one layer away from where the class lives will re-open it. `normalizeSalt`
maps `null`/`''` to "unsalted" *by design*, so every boundary that delegates to
it inherits that mapping — the guard has to refuse at the boundary.

## 4. Review pipeline

Hosted CodeRabbit found **zero** of ~120 findings across these PRs — rate-limited
or skipped on every one. Treat a green bot check as unverified until you know it
ran. What did work: **the CodeRabbit CLI, Codex, Greptile and independent
adversarial passes, run in parallel and asked to refute a named claim.** On the
final PR, Codex and an independent pass reached the *same two* findings
separately; that convergence is the strongest signal the process produced.

## 7. How to continue

**Sequence, highest value first.**

1. **Do not recruit an external lab yet.** Amendment 13 re-gated B6.2 for a
   reason B5.2 proved: the current task set is saturated by two baselines and
   never enters the code path the product actually runs. Rebuild the task layer
   first, then take the salt-versus-substrate decision *for that set*, then
   recruit. Spending the one external relationship on the current tasks wastes
   it.
2. **B6.1 is the highest-value landing.** `@ifc-lite/provenance` is still
   `private: true`, self-described "Prototype", with zero consumers outside
   `scripts/moonshot/`. The M1 final exam only means something once there is a
   product surface to make the edit on. Certificates into the collab layer's
   publish/review flow is that surface.
3. **Close B2.2 properly or restate it.** The mechanism is done and measured.
   What remains is delivery, and delivery is a hosted scorer — which is the same
   dependency as B6.2. Decide whether that is being built; if not, B2.2's row
   should say "mechanism closed, unfixed in force" rather than "CONFIRMED,
   UNFIXED", which now understates the work.
4. **B2.1 and B2.4 are the two open findings the program has been avoiding.**
   B2.4 in particular has been widened rather than attacked twice now.
5. **B6.3 is time-sensitive.** WGSL i64 or a WebGPU f64 extension erodes the
   novelty of the M6c negative result. No other bet has a shelf life.

**Working rules that earned their place.**

- Run several reviewers in parallel and ask each to *refute a named claim*.
  Independent convergence is the signal; a single clean pass is weak evidence.
- Verify a check by breaking the thing it watches. If nothing turns red, the
  check is decoration.
- A "0 differences" result is only evidence if the thing that produces the
  differences actually ran. Check the exit code first — a comparison against an
  unwritten file reports success.
- `git checkout <path>` restores from HEAD, which silently discards uncommitted
  work. Restore mutation experiments from a copy.
- Wall-clock figures bound to prose by the numeral gate must be re-quoted in the
  same commit as the artifact. This is documented in the B4.3 report header and
  still costs a round trip every re-run.
